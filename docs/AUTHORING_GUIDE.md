# Authoring Guide

Pistoris authoring guides are for artists and technical authors creating or
editing Arx resources in a DCC such as Blender. For exact node-name grammar,
defaults, and limits, use the [Authoring Reference](AUTHORING_REFERENCE.md).

The most intuitive starting point is usually a converted original asset. Export
a small native resource to GLB or OBJ, inspect its hierarchy and names in the
DCC, then modify that result. Use these guides when adding a feature or checking
a workflow rather than treating them as required front-to-back reading.

Shared terms, material syntax, and naming rules are defined in
[Shared Authoring Conventions](authoring/CONVENTIONS.md).
